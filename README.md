# Real-Time Customer Segmentation

## Project Overview
This project uses K-Means Clustering to group customers based on their income and spending behaviour.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Gradio

## Features
- Customer segmentation using K-Means
- Income and spending analysis
- Prediction for new customer data
- Cluster visualization
- Interactive, mobile-friendly interface

## Sample Dataset
The dataset contains customer income and spending values.

## Project Outcome
Customers are grouped into two categories:
- Regular Customers
- VIP Customers
